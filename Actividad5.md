GLOSARIO - FUNDAMENTOS DE COMPUTACIÓN

**1. Algoritmo**  
El algoritmo es una serie de pasos ordenados que nos permite hallar la solución de un problema o realizar una tarea en específica. El algoritmo está compuesto por una analogía clásica, en la que contiene una entrada (los ingredientes o los pasos iniciales que es lo que entra), el proceso (es donde van las operaciones o procedimiento), y la salida (resultado esperado).
Por ejemplo, un algoritmo puede servir para seguir un instructivo como el hacer una receta o ya sea para calcular cualquier problema que necesitemos

**2. Programa**  
Es un conjunto ejecutable escrito por medio de un lenguaje de programación para resolver un problema. Cada conjunto de instrucciones actúa como una serie de pasos que guían a la computadora a realizar las tareas específicas que queramos.

**3. Código fuente**  
Todos los programas que usamos a diario tienen un código fuente (Python, Java, C++, o JavaScript), del cual se trata de un conjunto de instrucciones escrita por algún lenguaje de programación que se la da al computador para que entienda y ejecute esa serie de pasos

**4. Lenguaje de programación**  
Un lenguaje de programación es un lenguaje formal o artificial, compuesto por símbolos y reglas expresadas en forma de instrucciones y relaciones lógicas, en el que se le permite al programador dar órdenes o establecer ciertas acciones consecutivas para la creación de programas.

**5. Sintaxis**  
La sintaxis se refiere a las reglas y estructuras, como también al orden de palabras y símbolos que se deben seguir al escribir código para que sea válido y comprensible para la computadora.
Si el programador no sigue la sintaxis de forma adecuada lo más probable es que el código pueda producir errores que impidan que el programa se ejecute, es por eso que el saber la sintaxis de un lenguaje permite entender mejor su función.

**6. Variable**  
Es un espacio en la memoria física o virtual de una computadora que se utiliza para guardar un dato cuyo valor puede cambiar durante la ejecución del programa. Cada variable puede tener un nombre asignado que se refiera al valor guardado, dichos datos almacenados pueden cambiar de valor o ser contantes.

**7. Constante**  
Es un dato que guarda un valor que no cambia durante la ejecución de un programa. Ejemplo: PI = 3.1416
Se trata como una variable común, a excepción de que su valor no puede ser cambiado después de que se haya definido. Las constantes son utilizadas en programas para evitar errores, asegurando que ciertas variables y valores permanezcan sin ser alteradas

**8. Tipo de dato**  
Indica qué clase de información puede guardar una variable o constante.
Cada tipo de dato tiene propiedades y operaciones específicas con él, por ejemplo: número entero, decimal, texto, carácter o verdadero/falso.

**9. Operador**  
Es un símbolo que se utiliza para realizar una operación o comparar valores. Ejemplos: +, -, *, /, >, <, ==.
Los operadores pueden realizar varias acciones como asignar, o comparar valores, realizar cálculos aritméticos, etc

**10. Expresión**  
Es una combinación de valores, variables y operadores que produce un resultado. Ejemplo: 5 + 3 da como resultado 8.
Las expresiones pueden ser aritméticas, relacionales, lógicas o de otros tipos, según lo que se quiera lograr

**11. Condicional**  
Es una estructura que permite que el programa tome una decisión dependiendo de si se cumple una condición. Ejemplo: Si la edad es mayor o igual a 18, mostrar "Mayor de edad".
Esto permite que los programas sean dinámicos, inteligentes y adaptables.

**12. Bucle**  
Es una estructura que permite repetir una o varias instrucciones mientras se cumpla una condición o durante un número determinado de veces. Ejemplo: repetir un mensaje 10 veces.
La información se puede ir cambiando y luego las instrucciones siguientes se aplicarán sobre esos nuevos datos, dando lugar a una enorme cantidad de posibilidades.

**13. Función**  
Es un bloque de código que realiza una tarea específica y puede utilizarse varias veces dentro de un programa.
El nombre de la función, el tipo de dato que retorna y entre paréntesis los parámetros, separados con “,” cada uno con su tipo, y finalmente retorna el resultado para el invocador.

**14. Parámetro**  
Es una variable que se define dentro de una función para recibir un dato que necesita para realizar su tarea. Ejemplo: en sumar (a, b), a y b son parámetros.
Un parámetro es una propiedad intrínseca del procedimiento, incluida en su definición, si un procedimiento tiene parámetros, la parte de su definición que especifica los parámetros se llama su lista de parámetros.

**15. Argumento**  
Los argumentos son las expresiones proporcionadas al procedimiento cuando se llama, generalmente una expresión que coincide con uno de los parámetros, de otra manera se refiere al valor que se proporciona a una función cuando la llamamos. Ejemplo: en sumar (5, 3), 5 y 3 son argumentos.

**16. Retorno**  
Es el resultado que una función devuelve después de realizar su tarea.
Los valores de retorno son importantes porque nos permiten ampliar la modularidad y reutilización de nuestras funciones. Ejemplo: una función que suma dos números puede retornar 8.

**17. Arreglo**  
Es una estructura que permite guardar varios datos del mismo tipo dentro de una sola variable, organizados mediante posiciones o índices, y es una de las más utilizadas pues permite organizar la información de forma ordenada y accesible, también se le conoce como array. Ejemplo: [1, 2, 3, 4].

**18. Objeto**  
Es una estructura que agrupa datos y acciones relacionadas para representar algo dentro de un programa, y esta divido en dos categorías principales: atributos y métodos. Ejemplo: un objeto, Persona puede tener nombre, edad y una función para saludar.

**19. Método**  
Es una función que pertenece a un objeto o clase y que permite realizar una acción relacionada con ese objeto, como cambiar el estado de uno objeto, calcular un valor, interactuar con otros objetos, etc. Ejemplo: un método saludar () dentro de un objeto Persona.

**20. Evento**  
Se refiere a una acción o suceso específico que ocurre durante la ejecución de un programa y que puede provocar una respuesta. Ejemplos: hacer clic en un botón, presionar una tecla o mover el mouse.

**21. Compilador**  
Es un programa que toma el código escrito por un programador y lo transforma, generalmente antes de ejecutarlo, a un formato que la computadora puede entender y ejecutar. También puede detectar errores durante este proceso. Los compiladores desempeñan un papel importante, ya que permite escribir código en lenguajes de alto nivel que son más fáciles de entender y mantener. Ejemplo: En C++, un compilador como GCC convierte un archivo .cpp en un programa ejecutable.

**22. Intérprete**  
Es un programa que analiza y ejecuta el código de un lenguaje durante la ejecución, normalmente procesando las instrucciones de manera progresiva. Los intérpretes funcionan mediante la lectura y ejecución de código escrito en un lenguaje de programación específico. Por ejemplo, en Python utiliza un intérprete para ejecutar un archivo .py

**23. Depurador (Debugger)**  
Es una herramienta que permite revisar un programa mientras se ejecuta para encontrar y corregir errores. Permite detener el programa y observar qué está sucediendo.
Si una variable tiene un valor incorrecto, podemos colocar un punto de interrupción y revisar su contenido con el debugger de VS Code.
Por este motivo, muchos depuradores no solo analizan el código fuente del programa, sino también su interacción con el sistema operativo que lo ejecuta y con los elementos de hardware

**24. IDE**  
Es un entorno de desarrollo que reúne en un mismo programa herramientas para escribir, ejecutar, probar y depurar código. Se encargan de ayudar a los desarrolladores a organizar su flujo de trabajo y solucionar problemas, analiza el código mientras se escribe, así que las fallas causadas por errores humanos se identifican en tiempo real.
Visual Studio y IntelliJ IDEA son ejemplos de IDE.

**25. Editor de código**  
Es un programa informático utilizado principalmente para escribir y modificar código. Puede incluir funciones como resaltado de sintaxis, autocompletado y detección de errores
Un editor de código debe ser fácil de usar, tener características útiles y proporcionar una experiencia de edición de código fluida y sin problemas.
Visual Studio Code permite escribir programas en Python, JavaScript, C++, entre otros lenguajes

**26. Biblioteca (Library)**  
Es un conjunto de código ya creado que podemos utilizar en nuestros programas para realizar determinadas tareas sin tener que programarlas desde cero. Son colección de fragmentos de código que se guardan agrupadas para que se pueda reusar.
En Python, math proporciona funciones para realizar operaciones matemáticas

**27. Framework**  
Es una estructura de herramientas, reglas y código previamente preparado que sirve como base para desarrollar aplicaciones de una determinada manera. Los tipos de frameworks varían según el propósito y el área de aplicación.
Flutter proporciona una estructura y herramientas para crear aplicaciones multiplataforma

**28. API**  
Es un conjunto de reglas y mecanismos que permiten que diferentes programas o servicios se comuniquen entre sí y puedan intercambiar información o utilizar funciones. Las API pueden permitir a estos servicios o redes sociales limitar qué funciones quieren que las aplicaciones de terceros puedan utilizar. Una aplicación del clima puede utilizar una API para obtener información meteorológica de un servidor

**29. Repositorio**  
Es un espacio donde se almacena y organiza un proyecto de software junto con sus archivos y, normalmente, su historial de cambios puede contener código, documentación, imágenes y otros recursos relacionados con un proyecto. Ejemplo: Un proyecto de una página web puede estar guardado en un repositorio de GitHub.

**31. Control de versiones**  
Es un sistema que permite registrar los cambios realizados en los archivos de un proyecto para poder consultar su historial, comparar modificaciones o recuperar versiones anteriores.
Si modificamos un programa y después deja de funcionar, podemos recuperar una versión anterior mediante el control de versiones.

**32. Git**  
Es un sistema de control de versiones distribuido que permite registrar cambios en proyectos y trabajar con diferentes versiones del código.
Podemos utilizar git commit para guardar un conjunto de cambios en el historial del proyecto.

**33. GitHub**  
Es una plataforma que permite alojar repositorios Git en Internet y facilita la colaboración entre personas que trabajan en proyectos de software.
Un equipo puede subir su proyecto a GitHub para que todos sus integrantes puedan trabajar en él.

**34. Rama (Branch)**  
Es una línea de trabajo independiente dentro de un repositorio que permite realizar cambios sin modificar directamente otra rama, como la principal.
Podemos crear una rama llamada login para desarrollar el sistema de inicio de sesión sin afectar main.

**35. Commit**  
Es un registro de un conjunto de cambios realizados en un proyecto. Sirve para guardar un punto específico del historial y describir qué se modificó.
Después de corregir un error podemos hacer un commit con el mensaje "Corregir error en login

**36. Merge**  
Es el proceso de unir los cambios realizados en una rama con otra rama.
Cuando terminamos una nueva función en login, podemos hacer merge para incorporar esos cambios a main

**37. Callback**  
Es una función que se proporciona a otra función para que sea ejecutada posteriormente, con normalidad cuando ocurre determinada acción o termina un proceso.
En JavaScript podemos proporcionar una función que se ejecute cuando termine una operación o cuando el usuario haga clic en un botón

**38. Programación síncrona**  
Es una forma de ejecutar instrucciones en la que una tarea debe terminar antes de que el programa continúe con la siguiente.
Si un programa tiene tres funciones síncronas, normalmente ejecutará la primera, esperará a que termine y después pasará a la segunda

**39. Programación asíncrona**  
Permite iniciar una tarea que puede tardar cierto tiempo y continuar realizando otras operaciones sin tener que esperar a que termine inmediatamente.
Una página web puede solicitar información a un servidor y continuar funcionando mientras espera la respuesta

**40. JavaScript**  
Es un lenguaje de programación utilizado principalmente para agregar comportamiento e interacción a páginas web, aunque también puede utilizarse para desarrollar aplicaciones de servidor y otros tipos de software.
JavaScript puede utilizarse para hacer que un botón de una página muestre un mensaje al hacer

**41. TypeScript**  
Es un lenguaje basado en JavaScript que agrega características como los tipos estáticos y posteriormente puede convertirse a JavaScript para ejecutarse en entornos compatibles.
Podemos declarar let edad: number = 17; en TypeScript para indicar que la variable edad debe contener un número.
